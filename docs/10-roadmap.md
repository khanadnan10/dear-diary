# 10 — Future Roadmap

## Post-MVP Priority Order

| Phase | Feature | Notes |
|-------|---------|-------|
| v1.1 | Encrypted export/backup | Local export to encrypted file; no cloud |
| v1.1 | Calendar view | Browse entries by month |
| v1.2 | Tags | Simple freeform tags; searchable |
| v1.2 | Audio transcription (on-device) | Using Whisper or Apple/Google on-device API |
| v2.0 | Optional encrypted sync | User-controlled; E2EE only |
| v2.x | Video journaling | After audio is stable |

## Features That Will Never Be Added

Per the product philosophy, the following are permanently excluded:

- Any form of social sharing
- AI analysis or insights on entries
- Mood tracking or journaling prompts
- Gamification (streaks, badges, points)
- Ads or monetization tied to content
- Any analytics that sends data off-device

## Evaluation Criteria for New Features

Before any feature is added, it must pass:

1. **Privacy test** — Does it keep all data on-device?
2. **Calm test** — Does it add pressure or distraction?
3. **Philosophy test** — Does it serve emotional unloading?

If any answer is "no" or "maybe", the feature is deferred.
